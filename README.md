# ArugaBai Static Site

This folder is a plain static version of the ArugaBai landing page.

Upload these files directly to GoDaddy `public_html`:

- `index.html`
- `styles.css`
- `script.js`
- `.htaccess`
- `assets/`

No Node.js, pnpm, React, Vite, or build step is required.

The waitlist form is currently a static demo handler. To collect real submissions, connect the form in `index.html` to a service such as Formspree, Basin, Google Forms, or your own endpoint.
